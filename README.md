# Adama Hotel Booking Platform

A full-stack hotel booking platform for Ethiopia, starting with **Adama**, **Addis Ababa**, and **Hawassa**, with production-ready features including:

- Multi-city support
- AI hotel recommendations
- SMS booking via Ethio Telecom
- Telebirr payment integration
- Role-based dashboards (Admin, Owner, User)
- Modern Tailwind UI with analytics charts
